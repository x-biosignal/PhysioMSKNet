# Load Paper Impact Scores from fig3a.xls

Load Paper Impact Scores from fig3a.xls

## Usage

``` r
.loadPaperImpactScores(dir)
```

## Arguments

- dir:

  Path to extdata directory.

## Value

A list with:

- real:

  data.frame with columns: muscle_index, degree, impact_score

- null:

  data.frame with columns: degree, impact_score, null_run
