# Compute activation z-scores

Computes z-score of activation change between current and baseline.

## Usage

``` r
.computeActivationZScore(current_rms, baseline_rms, baseline_sd)
```

## Arguments

- current_rms:

  Numeric vector of current RMS values.

- baseline_rms:

  Numeric vector of baseline RMS values.

- baseline_sd:

  Numeric vector of baseline standard deviations.

## Value

Numeric vector of z-scores.
