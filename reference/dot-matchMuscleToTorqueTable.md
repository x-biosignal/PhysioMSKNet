# Fuzzy-match muscle names to moment arm lookup

Fuzzy-match muscle names to moment arm lookup

## Usage

``` r
.matchMuscleToTorqueTable(muscle_names, hg)
```

## Arguments

- muscle_names:

  Character vector of muscle names from EMG channels.

- hg:

  An MSKHypergraph object.

## Value

A data.frame with matched entries and hg muscle indices.
