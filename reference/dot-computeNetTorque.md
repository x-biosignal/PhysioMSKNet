# Compute net torque per joint

Compute net torque per joint

## Usage

``` r
.computeNetTorque(activation, moment_arms, directions)
```

## Arguments

- activation:

  Numeric vector of muscle activation values.

- moment_arms:

  Numeric vector of moment arm magnitudes.

- directions:

  Integer vector of +1/-1 directions.

## Value

Numeric scalar: net torque.
