# Active force-length multiplier

Gaussian active force-length curve, peaking at the optimal fiber length
(normalised length 1).

## Usage

``` r
forceLengthActive(norm_len, width = 0.45)
```

## Arguments

- norm_len:

  Normalised fiber length (optimal = 1).

- width:

  Gaussian width parameter (default 0.45).

## Value

Multiplier in `[0, 1]`.
