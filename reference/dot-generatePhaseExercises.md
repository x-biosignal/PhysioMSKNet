# Generate exercises for a rehab phase

Generate exercises for a rehab phase

## Usage

``` r
.generatePhaseExercises(muscles, phase, intensity = "moderate")
```

## Arguments

- muscles:

  Character vector of muscle names.

- phase:

  Character, rehab phase name.

- intensity:

  Character, intensity level ("low", "moderate", "high").

## Value

data.frame with exercise prescriptions.
